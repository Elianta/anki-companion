# Ankify — App Guide

Описание текущей функциональности приложения, пользовательских сценариев и правил работы с данными.

## 1. Назначение приложения

Ankify помогает создавать карточки для Anki из английских и польских слов или выражений. Пользователь получает варианты перевода на русский, выбирает значение, сохраняет его в черновики, проверяет сгенерированные поля и скачивает CSV для импорта в Anki.

Основной сценарий:

**Поиск → Выбор значения → Сохранение в черновики → Генерация полей → Проверка и редактирование → Выбор карточек → Создание экспорта → Скачивание CSV.**

| Термин                   | Значение                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| Значение / Sense         | Один вариант перевода слова с пояснением, частотностью и примерами                         |
| Черновик / Draft         | Сохранённое слово с выбранным значением и типом карточки; полей для Anki может ещё не быть |
| Готовая карточка         | Черновик со сгенерированными полями; доступен для редактирования и экспорта                |
| Тип карточки / Note type | Шаблон Anki, определяющий набор полей                                                      |
| Экспорт / Export         | Сохранённый набор CSV-файлов из выбранных готовых карточек                                 |
| История / History        | Карточки, уже включённые в экспорт                                                         |

Экспорт считается выполненным при создании файлов, до скачивания и импорта в Anki. Приложение не отслеживает, были ли карточки импортированы.

Подписи интерфейса преимущественно английские. Переводы — русские; определения и примеры — на языке исходного слова. Выбор EN/PL меняет язык поиска, а не язык интерфейса.

## 2. Разделы и общие настройки

| Раздел             | Назначение                                                      | Адрес      |
| ------------------ | --------------------------------------------------------------- | ---------- |
| Search / Поиск     | Поиск слова, выбор значения и сохранение в черновики            | `/`        |
| Drafts / Черновики | Генерация, редактирование и выбор карточек для экспорта         | `/draft`   |
| Export / Экспорт   | Скачивание CSV из созданных экспортов                           | `/export`  |
| History / История  | Ранее экспортированные карточки, возврат в черновики и удаление | `/history` |

Все четыре раздела доступны через общую навигацию. На мобильном она находится снизу, на десктопе — в шапке. Адрес `/senses` перенаправляет на `/`: значения отображаются на странице поиска, отдельного экрана для них нет.

Счётчик Drafts показывает количество ещё не экспортированных черновиков, включая записи без готовых полей. При нуле счётчик скрывается.

Уведомления появляются сверху экрана и закрываются автоматически или кнопкой закрытия. Ошибки поиска, сохранения и генерации отображаются как ошибки; ограничение частоты запросов — как отдельное предупреждение с временем ожидания, если сервер его сообщил.

### Исходный язык

В поисковой форме доступны EN и PL. По умолчанию выбран EN. Выбор запоминается между посещениями. Смена языка сохраняет текст ввода, но сбрасывает показанные результаты. Во время поиска менять язык нельзя.

### AI-модель

Выбор модели доступен на всех страницах. На мобильном кнопка в шапке открывает панель `Choose AI model`; на десктопе используется список. Выбор запоминается между посещениями и используется в последующих запросах поиска и генерации.

## 3. Search: поиск и выбор значения

### Поиск

Поле `Word or phrase` принимает слово, выражение или короткую фразу длиной до 50 символов. Контекст можно добавить в квадратных скобках, например `zamek [do drzwi]`. Сервер возвращает исходное слово для карточки отдельно от контекста; оно может отличаться от введённой строки.

Поиск запускается кнопкой Search или Enter. Пробелы по краям удаляются перед отправкой; пустой запрос не отправляется. Повторный запрос во время выполнения текущего блокируется.

Во время запроса:

- Кнопка поиска и выбор языка недоступны.
- Поле остаётся редактируемым; изменение текста не меняет уже отправленный запрос.
- Показан статус `Searching for “…”` с отправленным запросом и сообщением об ожидании.
- Показаны два временных блока загрузки значений.

После ответа значения появляются под поисковой формой. При ошибке появляется уведомление, текст ввода сохраняется. При ограничении частоты запросов приложение сообщает о необходимости подождать, включая время ожидания, если сервер его передал.

### Результаты и выбор

Заголовок `Possible senses for …` использует слово из ответа сервера. Поиск запрашивает у AI не больше двух наиболее релевантных значений. Каждый вариант может содержать:

- Русский перевод.
- Часть речи.
- Пояснение к значению.
- Частотность: low, medium или high.
- Пример на исходном языке с русским переводом.

Если необязательных данных нет, соответствующие сведения не отображаются. По умолчанию выбран первый вариант. Выбор одиночный: нажатие на другой вариант заменяет его. С клавиатуры доступны стрелки вверх и вниз, Home, End, Enter и пробел.

Если значений нет, приложение сообщает `No senses found for …` и предлагает уточнить запрос или контекст.

### Сохранение значения

Для выбранного значения доступны выбор Note type и действие `Save to draft`. Типы зависят от языка:

| Язык | Доступные типы                                           | По умолчанию  |
| ---- | -------------------------------------------------------- | ------------- |
| EN   | `EN: Default`                                            | `EN: Default` |
| PL   | `PL: Default`, `PL: Verbs`, `PL: Nouns`, `PL: Verbs Inf` | `PL: Default` |

У английского один тип, поэтому его селектор недоступен. Для польского тип выбирает пользователь; автоматического выбора по части речи нет.

Сохранение записывает слово, выбранное значение и тип в черновики, запускает генерацию полей в фоне и показывает уведомление об успехе. Пользователь остаётся на странице поиска с текущими результатами; ждать окончания генерации не требуется. Пока идёт сохранение, повторное сохранение и смена типа блокируются. При ошибке остаются доступны результаты, а сообщение появляется под результатами и в уведомлении.

Повторное сохранение того же результата поиска с тем же языком и типом не создаёт второй черновик. Другой тип может создать отдельную карточку. Это правило относится к конкретному результату поиска: новый поиск того же слова не гарантирует отсутствие дублей.

Текст запроса и результаты хранятся только в текущем открытии страницы. При переходе в другой раздел или перезагрузке они сбрасываются; выбранный язык сохраняется.

## 4. Drafts: подготовка карточек

Drafts содержит ещё не экспортированные черновики. Новые записи идут перед старыми. В одном списке могут быть разные языки, типы карточек и состояния готовности.

Каждый черновик показывает Term, Translation и Note type. Доступные действия:

| Действие           | Поведение                                                                                                               |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| Выбор для экспорта | Доступен только при наличии сгенерированных полей                                                                       |
| Смена Note type    | Сбрасывает прежние поля и запускает генерацию по новому шаблону                                                         |
| View card          | Открывает редактор полей готовой карточки                                                                               |
| Generate card      | Создаёт поля карточки, если их ещё нет                                                                                  |
| Regenerate card    | Заменяет поля результатом текущей модели; доступен, если готовая карточка создана другой моделью или модель не записана |
| Удаление           | Удаляет один черновик из локального хранилища                                                                           |

Для EN тип изменить нельзя. Смена глобальной модели не отменяет готовность карточки: прежние поля можно редактировать и экспортировать. Перегенерация может перезаписать ручные изменения.

Во время ручной генерации повторная генерация той же карточки блокируется. После успешного завершения список обновляется. Ошибки генерации и смены типа отображаются уведомлениями; для серверного ограничения частоты запросов показывается время ожидания, если оно известно.

### Выбор и экспорт

`Select all ready cards` выбирает все готовые карточки; повторное нажатие снимает выбор. Если готовых карточек нет, действие недоступно. У неготовых карточек выбор для экспорта недоступен.

При смене типа ранее выбранная карточка временно не учитывается в количестве выбранных, пока у неё нет готовых полей. После успешной генерации её выбор восстанавливается.

Панель `Export selected` показывает количество выбранных готовых карточек. Без выбора экспорт недоступен. Во время создания файлов повторное нажатие блокируется и отображается `Exporting…`.

После успеха:

1. Создаётся набор CSV-файлов.
2. Выбранные карточки помечаются экспортированными и исчезают из Drafts.
3. Эти карточки становятся доступны в History.
4. Приложение переходит в Export для скачивания файлов.

Выбор карточек сбрасывается при уходе из Drafts. Для загрузки списка предусмотрены состояния ожидания, пустой очереди и ошибки.

### Фоновая генерация

Генерация, запущенная сохранением значения в Search, продолжает работу в фоне. Её ошибка не удаляет черновик: карточку без полей можно сгенерировать вручную в Drafts. Сейчас ошибка фоновой генерации не имеет отдельного уведомления, а уже открытый список Drafts не обновляется автоматически при её завершении. Повторное открытие страницы загружает актуальные данные.

## 5. Редактор полей карточки

Редактор открывается действием `View card` в Drafts. Панель `Card fields` показывает исходное слово, тип карточки и все сгенерированные поля. Значения редактируются текстовыми полями; длинный список доступен через прокрутку.

- Изменения записываются только по `Save`.
- `Cancel` или закрытие панели отменяет несохранённые изменения.
- Во время сохранения повторное сохранение недоступно, кнопка показывает `Saving…`.
- После успеха панель закрывается и список Drafts обновляется.
- При ошибке появляется уведомление; панель остаётся открытой для повторной попытки.
- Пустые значения допустимы.

Предпросмотра лицевой и обратной стороны карточки нет: редактор изменяет данные для импорта в Anki. Подтверждения при закрытии с несохранёнными изменениями нет.

## 6. Export: архив CSV

Export содержит созданные наборы файлов от новых к старым. Набор включает дату и время создания, раскрываемый блок `Words (N)` и отдельную кнопку скачивания для каждого Note type, например `PL: Verbs CSV`.

`N` — количество экспортированных карточек, а не обязательно уникальных слов. Списки слов раскрываются независимо друг от друга. Дата и время отображаются в часовом поясе браузера.

Один экспорт создаёт один CSV на каждый представленный тип карточки. Выбор нескольких типов создаёт несколько файлов. В каждом файле находятся поля соответствующего шаблона и служебные строки для импорта в Anki, включая разделитель, имена столбцов и столбец Note type.

Скачивание сохраняет файл с именем, заданным при создании экспорта. Оно не удаляет экспорт и не меняет состояние карточек. Сохранённые файлы можно скачивать повторно, в том числе после удаления или возврата соответствующих записей из History.

Для страницы предусмотрены загрузка, отсутствие экспортов и ошибка загрузки. Удаления наборов экспортов, выбора колоды, прямой отправки в Anki и подтверждения импорта в приложении нет.

## 7. History: экспортированные карточки

History содержит ранее экспортированные карточки. Порядок — от новых черновиков к старым по их созданию, а не по времени экспорта.

Запись показывает Term, Translation и Note type, доступный только для чтения. У неё есть чекбокс выбора для удаления и действие `Restore draft`. Редактора полей в History нет: для изменения типа или содержимого карточку возвращают в Drafts.

### Пагинация и выбор

На странице отображается до 12 карточек. Если страниц несколько, доступны стрелки перехода и номера страниц. Пагинация показывает до пяти последовательных номеров вокруг текущей страницы, а также первую и последнюю страницы; пропуски обозначаются многоточием.

`Select all (N items)` выбирает всю историю, включая другие страницы. При частичном выборе чекбокс отражает это состояние. Выбор отдельных карточек сохраняется между страницами и сбрасывается при уходе из History.

### Возврат и удаление

`Restore draft` снимает статус экспорта у одной карточки. Она исчезает из History и появляется в Drafts с прежними сгенерированными полями. Другие выбранные записи остаются выбранными. Пользователь остаётся в History; автоматического перехода нет.

Панель удаления показывает число выбранных записей. `Delete selected` недоступна без выбора. Во время удаления отображается `Deleting…`. Пока выполняется удаление или возврат карточки, выбор и действия с карточками блокируются.

Удаление выполняется без подтверждения и отмены. При частичной ошибке успешно удалённые записи исчезают, а неудачно удалённые остаются выбранными для повторной попытки. Ошибка возврата оставляет карточку в History. Если после операции текущей страницы больше нет, отображается последняя доступная страница. При удалении или возврате последней записи появляется пустое состояние.

Удаление и возврат из History не меняют уже сохранённые CSV-файлы. Возвращённую карточку можно редактировать и включать в новый экспорт.

Для History предусмотрены загрузка, пустая история, ошибка загрузки и ошибки действий.

## 8. Типы карточек и поля

Названия Note type соответствуют шаблонам Anki и сохраняются в экспорте.

| Тип             | Содержание                                                                                                                               | Полей |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| `EN: Default`   | Слово или выражение, IPA, определение, русский перевод, два примера с пропусками и русскими переводами, синонимы, формы глагола          | 12    |
| `PL: Default`   | Слово или выражение, определение, русский перевод, два примера с пропусками и русскими переводами, синонимы                              | 10    |
| `PL: Verbs`     | Глагол, определение, перевод, 18 личных форм с отдельным примером для каждой, вид и видовая пара                                         | 41    |
| `PL: Nouns`     | Существительное, определение, перевод, два примера с пропусками и переводами, по семь падежных форм единственного и множественного числа | 23    |
| `PL: Verbs Inf` | Инфинитив, определение, перевод, пример с инфинитивом, его вариант с пропуском и русский перевод, 18 личных форм                         | 24    |

Основные поля — `Word` или `Verb`, `Definition` и `Translation`. В английском шаблоне также есть `IPA` и `VerbForms`.

Обычные примеры представлены группами `Example1`, `Example1Spaces`, `Example1RU` и аналогичной группой `Example2`. Суффикс `Spaces` обозначает замену изучаемого слова или его формы подчёркиваниями; `RU` — русский перевод предложения.

У польских глаголов личные формы включают три группы по шесть: настоящее или простое будущее в зависимости от шаблона и вида; прошедшее мужского рода; прошедшее женского рода. У существительных сохраняются падежные формы обоих чисел.

## 9. Хранение данных и ограничения

- Черновики, их поля, признаки экспорта, списки слов и содержимое CSV хранятся локально в IndexedDB текущего браузера.
- Исходный язык и выбранная AI-модель сохраняются локально между посещениями.
- Поисковый текст, результаты поиска, выбор карточек и страница History не сохраняются между открытиями соответствующего экрана.
- Аккаунтов и синхронизации между устройствами или браузерами нет. Очистка данных сайта удаляет локальные карточки, историю и экспорты.
- Поиск и AI-генерация требуют соединения с сервером. Уже сохранённые данные не требуют повторной AI-генерации для редактирования или скачивания.
- Приложение поддерживает установку как PWA.
- Сообщения об ограничении частоты запросов не запускают автоматический повтор или обратный отсчёт; пользователь повторяет действие самостоятельно.
- Приложение подготавливает файлы для Anki; импорт выполняется отдельно в Anki.
